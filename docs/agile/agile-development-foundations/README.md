# アジャイル開発の基礎理解：短いサイクルで価値を届け、品質を継続的に扱う仕組み

このディレクトリは、アジャイル開発を、単なる高速開発や会議・タスク管理の手法ではなく、短いサイクルで価値を届け、フィードバックから学び、継続的に改善するための考え方と実践として整理した入門・参照用資料です。

Agile Manifesto、Scrum、Kanban、開発の流れ、短いサイクルにおける品質活動、DevOps、AI(Artificial Intelligence:人工知能)支援を取り入れた開発、関連する発展領域の紹介などを扱います。

## 想定する読み手

- アジャイル開発へ初めて参加する人
- プロダクトマネージャー、開発者、QA(Quality Assurance:品質保証)、データ担当などとしてアジャイルチームへ参加する人
- ScrumやKanbanの用語は知っているが、開発全体の流れを整理したい人
- Backlog、Sprint、品質活動、リリース、運用後フィードバックのつながりを理解したい人
- Agileを会議やタスク管理の方法としてではなく、価値提供とフィードバックの仕組みとして捉えたい人
- AI支援を取り入れる場合の着目点や注意点を整理したい人
