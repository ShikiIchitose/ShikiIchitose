# QA職能入門：品質を作り、判断し、改善へ戻す仕組み

このディレクトリは、QA(Quality Assurance:品質保証)を、単なるテスト実行ではなく、品質を作り、判断し、改善へ戻すための職能として整理した入門・参照用資料です。

要求整理、テスト設計、自動化、品質ゲート、品質メトリクス、DQA(Data Quality Assurance / Data Quality Assessment:データ品質保証 / データ品質評価)、AI時代のQA、他職種連携などを扱います。

## 読み方

この資料は長いため、章ごとの分割版と統合版を用意しています。

- 全体構成を確認する場合: [outline.ja.md](outline.ja.md)
- 通読する場合: [full.ja.md](full.ja.md)
- 特定の章だけ読む場合: [chapters/](chapters/)
- 参考文献・参照情報を見る場合: [appendices/references.ja.md](appendices/references.ja.md)

まず全体像を確認したい場合は、[outline.ja.md](outline.ja.md) から読むことを想定しています。

## 想定する読み手

- QA職能を体系的に理解したい人
- QAをテスト実行だけでなく、品質活動全体として捉えたい人
- 開発、データ、分析、運用などの経験とQAの接点を考えたい人
- QA / QE(Quality Engineering:品質エンジニアリング) / SDET(Software Development Engineer in Test) / SET(Software Engineer in Test) 周辺の考え方を整理したい人
